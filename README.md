# Орден знаний 🌌

**Орден знаний** — это образовательное Telegram Mini App нового поколения для всех возрастов, сочетающее в себе элементы футуристической RPG, иммерсивного 3D-мира и продвинутого ИИ-наставника.

## 🚀 Видение проекта

Орден знаний превращает учебу в захватывающее приключение. Это не просто чат-бот, а полноценная образовательная экосистема с кинематографичным интерфейсом и геймифицированной прогрессией.

### Основные возможности:
- **Центральный Хаб 3D**: Интерактивное ядро академии, созданное на Three.js.
- **Магистр знаний**: Ваш персональный ИИ-наставник, который помогает осваивать сложные темы, дает подсказки и мотивирует.
- **Миры знаний**: Порталы в 10 школьных и университетских дисциплин.
- **Адаптивное обучение**: Контент подстраивается под ваш возраст, уровень знаний и цели.
- **RPG-система**: Уровни, опыт (XP), достижения и награды.
- **Премиальный дизайн**: Стилистика Glassmorphism, мягкие градиенты и современная типографика.

## 💻 Инструкция по запуску (Mac)

Для запуска проекта вам понадобится установленный **Node.js** (рекомендуемая версия 18 или выше).

### Web App
1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/mv-baranova/Ai-Academy.git
   cd Ai-Academy
   ```

2. **Установите зависимости:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Запустите сервер для разработки:**
   ```bash
   npm run dev
   ```
   После запуска приложение будет доступно по адресу `http://localhost:3000`.

4. **Сборка проекта:**
   ```bash
   npm run build
   ```

### Telegram Bot
Бот необходим для запуска Mini App внутри Telegram.

1. **Перейдите в папку бота:**
   ```bash
   cd bot
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Настройте переменные окружения:**
   Создайте файл `.env` на основе `.env.example` и укажите ваш `TELEGRAM_BOT_TOKEN` и `WEBAPP_URL`.

4. **Запустите бота:**
   ```bash
   npm start
   ```
