# Nexus Academy 🌌

**Nexus Academy** — это образовательное Telegram Mini App нового поколения для школьников, сочетающее в себе элементы футуристической RPG, иммерсивного 3D-мира и продвинутого ИИ-наставника.

## 🚀 Видение проекта

Nexus Academy превращает учебу в захватывающее приключение. Это не просто чат-бот, а полноценная образовательная экосистема с кинематографичным интерфейсом и геймифицированной прогрессией.

## 🤖 Telegram Бот и Mini App

Проект состоит из двух частей:
1. **Frontend**: Сама академия (Mini App).
2. **Bot**: Telegram-бот для запуска приложения.

### 📝 Инструкция по настройке бота

#### 1. Создание бота в BotFather
1. Откройте [BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/newbot`.
3. Следуйте инструкциям: выберите имя для бота и его системное имя (должно заканчиваться на `_bot`).
4. После создания вы получите **HTTP API Token** (выглядит как `123456789:ABCdef...`). Это ваш `TELEGRAM_BOT_TOKEN`.

#### 2. Настройка Mini App
1. В BotFather отправьте команду `/mybots`.
2. Выберите своего бота.
3. Нажмите **Bot Settings** -> **Menu Button** -> **Configure Menu Button**.
4. Отправьте ссылку на ваш развернутый Mini App (или используйте временную через `ngrok`).

#### 3. Настройка окружения
1. Перейдите в папку `bot`:
   ```bash
   cd bot
   ```
2. Создайте файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```
3. Откройте `.env` и вставьте ваш токен и URL приложения:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_из_BotFather
   WEBAPP_URL=ссылка_на_ваше_приложение
   ```

## 💻 Инструкция по запуску (Mac)

### 1. Запуск Frontend (Mini App)
```bash
# Из корня проекта
npm install --legacy-peer-deps
npm run dev
```
Приложение будет доступно по адресу `http://localhost:3000`. Для работы внутри Telegram вам понадобится публичный URL (например, через `ngrok http 3000`).

### 2. Запуск Бота
```bash
# В новом окне терминала
cd bot
npm install
npm start
```

### 3. Как открыть в Telegram
1. Перейдите к вашему боту в Telegram.
2. Нажмите `/start`.
3. Нажмите кнопку **"Открыть Nexus Academy"**.

## 🛠 Технологический стек
- **Frontend**: React + Vite + TypeScript
- **Bot**: Node.js + Telegraf
- **3D Graphics**: React Three Fiber / Three.js
- **Styling**: TailwindCSS
- **State Management**: Zustand
